# Retail Sales Analysis using MySQL

## Project Overview
This project analyses retail sales data using MySQL to understand revenue performance, product sales, category performance, and monthly revenue trends.

## Objectives
- Analyse order status and delivered revenue.
- Identify top-performing products.
- Compare revenue across product categories.
- Calculate monthly revenue and month-over-month growth.
- Perform basic data quality checks.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## Database Tables
- `customers` — customer details
- `products` — product names, categories, and prices
- `orders` — order dates and statuses
- `order_items` — products and quantities in each order

## SQL Concepts Practised
- SELECT, WHERE, ORDER BY
- Aggregate functions and GROUP BY
- INNER JOIN
- CASE statements
- Common Table Expressions (CTEs)
- Window functions: RANK() and LAG()
- HAVING
- Data quality checks

## Key Findings
- Total delivered revenue: ₹362,200
- Laptop was the highest-revenue product at ₹165,000.
- Electronics contributed ₹299,000 in delivered revenue.
- Monthly revenue increased from November to December 2025, then decreased slightly in January 2026.

## Dataset Note
This project uses sample practice data created for learning and portfolio purposes. The findings are illustrative and do not represent actual business performance.
